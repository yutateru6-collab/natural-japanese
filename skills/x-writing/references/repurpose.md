# 長文・note → X 再構成ルール

再構成は要約ではない。
**元の意味と事実を守りながら、Xで単独の投稿として読める一つの芯へ作り直す。**

## 1. まず媒体の殻を外す

元記事から次のような「その媒体だけの要素」を分離する。

- 長い前置き
- SEO用の説明
- note内関連記事への導線
- 大量のハッシュタグ
- 「詳しくは下記」「プロフィールから」など媒体固有の誘導
- 長文だから成立する補足

削るのは意味ではなく媒体の殻。

## 2. Spineを一つ選ぶ

元記事から次のどれか一つを主役にする。

- 一つの主張
- 一つの体験
- 一つの数字
- 一つの場面
- 一つの反論
- 一つの笑えるズレ

一投稿へ全部詰めない。
三つの強い要素があるなら三投稿に分ける候補として扱う。

## 3. コンテナを決める

### 単発投稿

一つの主張・場面・数字で完結できるとき。

### スレッド

順番が意味を持つ説明、経過、複数の具体例、反論処理が必要なとき。
文字数に収まらないだけで安易にスレッド化しない。

詳細は `threads.md`。

## 4. X用に作り直す

1. 元素材の芯を1文で言う
2. `hooks.md` で新しい冒頭を選ぶ
3. 元媒体の接続説明を削る
4. X単体で必要な最低限の背景だけ戻す
5. 本文がフックの約束を回収しているか確認する
6. `voice-and-humanizer.md` で本人の声とAI臭を点検する
7. `audit.md` を通す

## 5. 絶対に守るもの

- 元の主張
- 数字と単位
- 固有名詞
- 時系列
- 誰が何をしたか
- 本人が実際に語った体験の範囲

表現は変えてよい。意味は変えない。

## 6. note誘導型

投稿だけ読んでも最低限の価値を残す。
記事を読めばもう一段深くなる状態にする。

避ける:

- 「続きはnoteで」だけ
- 結論を隠すだけの釣り
- 架空のURL
- note本文にない強い予告

## 7. 採用しない成長ハック

外部スキルにある次の種のルールは固定ルールにしない。

- 「○%短くすれば伸びる」
- 「外部リンクは必ず返信へ」
- 「特定文字数が常に最適」
- 「この型がアルゴリズム上有利」とする未検証の断定

アルゴリズムやUIは変わる。必要なときだけ現行仕様を確認し、文章品質のルールと混同しない。
