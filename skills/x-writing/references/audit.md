# X投稿 公開前監査

監査は「バズりそうか」を採点するものではない。
**事実を壊していないか、Xで読めるか、本人の声が残っているか**を確認する。

## P0 Blocker

一つでもあれば修正してから出す。

- 元素材にない体験・数字・実績・会話を追加している
- 重要な条件や例外を落として意味が変わっている
- 架空URL、架空の引用、架空の研究を含む
- モデル内部記号や未処理テンプレートが残る
- フックが本文より強く、本文が約束を回収できない
- 他人の投稿の表現をそのまま模倣しすぎている

## P1 Warning

文脈を見て直す。

### 内容

- 一投稿に複数の主張を詰めすぎ
- 抽象論だけで具体がない
- 冒頭だけ刺激的で中身が弱い
- note本文の単なる要約になっている

### 文体

- `style-profile.md` から外れている
- 読点や接続語が増えすぎ
- 完璧な三項列挙、二項対比、短文連打が続く
- 自己啓発的な締めを人工的に追加
- 絵文字・ハッシュタグ・装飾が本文より目立つ

### X適合

- 一行目だけでは話題が分からない
- 改行が多すぎて縦に長いだけ
- 他媒体の「プロフィールから」「概要欄へ」などが残る
- URLやハッシュタグの使い方が目的と合っていない
- 単発で足りる内容を無理にスレッド化している

## 現行仕様が必要な項目

次は固定知識にしない。
投稿可否を厳密に判断する必要がある場合は、その時点のX公式仕様を確認する。

- 文字数上限と文字の重み付け
- Premiumの長文上限
- URLのカウント
- 画像・動画の添付制限
- 投稿・スレッドUIの仕様

「アルゴリズム上○○が有利」のような情報も、一次情報または十分な根拠がない限り監査の必須条件にしない。

## 最終5問

1. **True?** 元素材と事実が一致しているか
2. **One idea?** 読後に一つのことが残るか
3. **Hook paid?** 冒頭の約束を本文が回収したか
4. **Sounds like user?** 本人が自然に言いそうか
5. **Native enough?** 他媒体のコピーではなくX投稿として成立しているか

5つともYesなら完成。
